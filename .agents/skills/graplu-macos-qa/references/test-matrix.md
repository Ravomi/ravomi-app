# 测试矩阵

当前依据为 [PRD](../../../../PRD.md)、[DESIGN](../../../../DESIGN.md) 和 [AI_UI_RULES](../../../../AI_UI_RULES.md)。先记录被测入口和实现阶段；Agent 流程仅在接入后执行，未实现时写明未实现与阶段依据，不算通过。旧 Graplu / H&M 截图只作历史证据。

每行可以拆成子用例。报告记录操作、预期、实际、状态、证据；一张截图不能证明整行交互通过。

| ID | 层级 | 场景与验收点 |
| --- | --- | --- |
| SM-01 | 冒烟/核心 | 从已安装 app 启动，首页与菜单可见，无崩溃、黑屏、字体缺失；记录启动方式 |
| SM-02 | 冒烟/核心 | 新建文档、建立文字节点、中文/拉丁混排编辑，失焦与确认行为正确；真实中文输入法单列 |
| SM-03 | 冒烟/核心 | 另存测试 .prg、关闭重开，文本/节点/连线/分组保留；未保存关闭的取消/保存/放弃分支分别验证 |
| SM-04 | 冒烟/核心 | 创建/移动/删除后撤销和重做；一次拖动一次撤销，不残留推挤位移 |
| FN-01 | 回归 | 多文档切换、长中文文件名、脏状态、标签溢出、关闭按钮与新增入口 |
| FN-02 | 回归 | 单选/框选/拖动、平移/滚轮缩放、缩放锚点；原生触控板捏合单列人工验证 |
| FN-03 | 回归 | 创建分组、文字节点接收子节点、最后子节点移出恢复、嵌套组整体移动、锁定与撤销重做 |
| FN-04 | 回归 | 连线/箭头/缩远可读性、概览标题阈值、深浅嵌套组遮罩、概览命中与编辑 |
| FN-05 | 回归 | 图片与 SVG 导入、粘贴、角点等比缩放、取消拖动、保存重开、锁定成员不可缩放 |
| FN-06 | 回归 | 搜索/属性/右键菜单、禁用布局提示、无颜色项、快捷色条、多文档后图标仍在 |
| FN-07 | 回归 | 无效 .prg 与不可写保存目标的可见错误、取消后仍可编辑；只用测试目录，不改变系统权限 |
| MAC-01 | 平台 | 菜单实际显示的快捷键与 Cmd/Ctrl 行为，复制/粘贴、原生文件选择器、Finder 打开 .prg |
| MAC-02 | 平台 | Retina 清晰度、窗口调整、最小化恢复、全屏往返；多屏 DPI 与真实触控板按硬件可用性报告 |
| GUI-01 | GUI | 深色/浅色 × UI 100%/150%/200%，同场景同窗口截图，文字截断、层级、留白、透明背景可读性 |
| GUI-02 | GUI | 宽窗口及逻辑宽度 900/600/500 临界两侧，按被测入口检查侧栏/工具菜单折叠、标签不遮挡固定按钮、菜单不越界；不要求已移除的 Dock 存在 |
| GUI-03 | GUI | 默认/悬停/按下/焦点/选中/禁用，动画反向、中断、失焦与切文档后无残影 |
| GUI-04 | GUI | 键盘访问/图标名称/普通文字对比度目标 4.5:1；透明背景须按实际合成色检查 |
| GUI-05 | GUI/新设计 | 素净层次、清晰正文/控件/连线；猫为一体团子、双耳双眼、无嘴鼻尾脚，石墨黑配局部雾蓝紫细颗粒柔光，小尺寸可辨；旧资源与新版落地状态分列 |
| AG-01 | 接入后核心 | 真实任务拆解、模块连接、并行分支和上下文交接可查看；可暂停/调整/重试/审核，错误与等待人处理状态有文字；记录执行宿主与模拟边界 |
| PF-01 | 性能 | 100/1000/5000 节点，每档三次四阶段基准，推挤开启，保存 JSON/日志/退出码 |
| PF-02 | 性能 | 复杂 .prg 副本相同四阶段，记录节点/边/附件数量与文件哈希 |
| PF-03 | 性能 | 普通非基准窗口空闲 30 秒以上的 CPU/RSS，注明采样频率；连续重绘不能冒充空闲 |
| SRC-01 | 可选源码 | cargo fmt --all --check；cargo test --workspace --locked；cargo clippy --workspace --all-targets --locked -- -D warnings，可用 --release 复用缓存 |

首轮最小范围：SM-01 至 SM-04、GUI-01、PF-01。工具或时间限制可形成“验证不完整”的首轮报告，列出具体未覆盖格子与下一轮步骤，不虚构完成。
