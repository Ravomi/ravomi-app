# Ravomi 界面图标

界面图标用于导航、模块类型、动作和状态；保持简洁轮廓、统一视觉尺度、清晰对比，并提供可访问名称。当前规则见 [DESIGN](../../DESIGN.md) 与 [AI_UI_RULES](../../AI_UI_RULES.md)。团子猫是品牌与 Agent 形象，细颗粒柔光仅用于该形象，不应用于功能图标；品牌资源见 [BRAND](../branding/BRAND.md)。目录中的原始资源和许可来源保留如下。

## Sources and licenses

Lucide icons from `lucide-static@1.54.0`, downloaded from
`https://unpkg.com/lucide-static@1.54.0/icons/`.

Menu icons are copied unchanged from the Godot reference project,
`project-graph-godot/src/main/icons/lucide/`: file, view, axe, settings,
app-window, blocks, circle-help, save, undo, redo, folder-open, clock, plus,
download, upload, book-open, search, info, globe, x, copy, clipboard, trash-2,
type, palette and scissors. The command mapping follows
`src/main/main.gd` in that project. See GODOT-LUCIDE-LICENSE.txt for the
Lucide ISC and Feather MIT notices retained with those assets.

Remaining SVGs use the pinned upstream version above (see LICENSE).
