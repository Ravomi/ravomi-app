- 解决什么问题
  - 记录文件的版本
  - 比较与恢复修改
  - 支持多人并行开发
- 核心概念
  - 工作区、暂存区与仓库
    - 工作区：正在编辑的文件
    - 暂存区：准备进入下一次提交的内容
    - 本地仓库：保存提交历史和对象
  - 历史与引用
    - 提交：记录一次项目快照及相关信息
    - 分支：指向提交的可移动引用
    - HEAD：标识当前检出位置，通常指向分支
- 日常操作
  - git status：查看状态
  - git add：更新暂存区
  - git commit：创建提交
  - git log：查看提交历史
- 分支与协作
  - merge：合并开发历史
  - 冲突：需要协调的不同修改
  - 远程协作
    - fetch：获取远程对象与引用更新
    - push：向远程发送对象并请求更新引用
- 常见误解
  - Git 不等于 GitHub
  - commit 不等于 push
  - 分支不是复制一整份项目目录
