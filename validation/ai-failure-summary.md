# 协作失败原因可见性

2026-10-12。截图中的“什么是 git？”任务在模型调用前失败，运行记录明确报告未配置 DeepSeek API Key。原生界面输入的 Key 仅进程内有效；当前用户 Pi 凭据当时只有 OAuth 提供方，未配置 DeepSeek API-key。

沿用用户先前明确提供并再次确认的密钥，恢复用户本机 Pi API-key 配置，保留其他提供方，文件权限 0600。密钥未写入本仓库、项目归档或验证记录。

真实验证使用已安装内置 Pi 引擎、原失败 Run 的固定规划输入与相同模型。排除开发 shell 中另一个旧凭据的环境覆盖后，恢复的 Pi 凭据成功获得 `stopReason: stop` 及包含 `answer` 任务的 JSON 计划。此验证没有修改正在打开的原运行状态，也不将原失败 Run 标成成功。

界面改动：流程最新 Run 失败时，在折叠记录外直接显示目标、失败阶段、实际错误和“配置完成后重试”按钮。重试继续使用已有固定输入与权限路径，旧失败记录保留。
