# 画布内任务、无固定并发上限与原生 UI 检查

日期：2026-10-12。环境：Linux x86_64，当前 Cargo.lock；窗口烟测为 Xvfb/X11 + Mesa lavapipe、1280 × 800。软件 Vulkan 仅用于功能和截图检查，不代表硬件 GPU 性能。未验收 macOS/Windows。

## 本次行为

- 选中文本或分组按 Space 可提交文字任务；无需填写外部项目和源码路径。显式附加外部代码时仍校验目录与路径，不隐式读取当前目录。
- 输入、输出和生成文件经现有协作归档随 `.mio` 保存。正在执行的运行仍由本机运行库管理；未保存的更新不宣称已写入项目文件。
- 去除固定任务数量、同时执行数量、流程数量及累计调用次数门槛。所有满足依赖的任务可派发；旧 `maxCalls` 字段仅兼容反序列化，不再控制执行。暂停、停止、固定输入重试、依赖顺序及单次运行超时保留。
- 线程启动失败进入运行错误记录；模型服务限流及机器资源仍可能使执行失败，无数量门槛不代表无限计算能力。动态自主派生子代理仍未实现。
- 显式释放运行目录锁，避免重复文件句柄延迟关闭导致已经停止的运行库无法重新打开。

## 自动回归

`cargo fmt --all --check`、`cargo test --release --workspace --locked`（307 通过、27 忽略）、`cargo clippy --release --workspace --all-targets --locked -- -D warnings` 和 `cargo build --release --locked` 通过。忽略项需要 GPU、特定文件或真实模型配置，不将它们记为已验收。目录锁修复后相关库测试额外连续三轮通过。

- 可控执行器同时阻塞并计数 20 个独立 Agent，确认 20 个都进入执行，释放后全部完成；不是 20 路真实模型调用。
- 无目录任务完成后保存 `.mio`，删除本机运行记录再重开，检查固定运行和输出仍在归档内。
- 暂停允许在途分支收尾，下游任务等待恢复；重复文件句柄存在时，释放持锁对象后允许新的写入者获取锁。
- 首页设置打开点击不被当作外部点击立即关闭；原有 Escape 与外部点击关闭回归继续保留。

## 窗口检查范围

检查首页、画布菜单、设置、搜索、节点属性、右键菜单、协作面板、快捷键、关于、恢复、PNG 导出配置和错误提示。组合覆盖浅色 100%、深色 150% 和深浅色 200%；不是每个组件与每个缩放的全排列。长内容使用滚动，关闭和确认操作保持可访问。连线标题样式同时经源码检查与编译验证。

修复协作面板的标题和滚动渐隐，错误提示、快捷键和连线标题复用共享主题；主按钮文字居中。截图与自动化脚本位于未纳入版本控制的 `results/ui-audit/`。本轮不将系统文件选择器、真实中文 IME、模型质量或 macOS 标题栏视为已验收。

旧的 [画布协作记录](canvas-ai-workflows.md) 中“必须配置项目”“最多两个 Agent”和画布不包含完整历史等描述属于当时版本，现已由本记录及 [存储验证](storage-mio-v2.md) 更新。
