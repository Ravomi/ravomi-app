# 编辑结束与空白双击的交接

2026-10-12，Linux。此前放宽双击间隔没有解决编辑器吞掉首击的问题。

原生文字编辑器现在在边界外的左键按下时提交，清理文字焦点，并让该次按下进入画布点击识别；原先等待点击释放，再通过 `active_at_start` 拦截整帧，导致第二击成为画布的第一次点击。菜单、弹窗、输入法组合、首次编辑帧及真实拖动继续使用既有保护。

回归测试区分区域内按下、区域外按下和释放。该修复针对确认的输入交接缺口，不声称排除全部触控板或系统事件丢失情形；Wry 内嵌 WebView 编辑入口不在本次修改范围。

Linux Xvfb / Vulkan 软件渲染下，实际双击 Git 文本进入编辑，再双击空白区域并输入 new：节点从 7 增至 8，新节点立即进入编辑。操作只针对独立测试进程，不修改用户项目。
