# 触控板灵敏度调整

2026-10-12。用户反馈双指拖动画布过慢，并反馈缩放速度异常。

核对本机锁定 winit 0.30.13 的 macOS / Wayland 源码：精确滚动先转为物理像素，当前导航除以窗口 scale factor 是必要换算，不以删除 DPI 换算来提速。

- 双指像素滚动平移、组合手势平移统一提高至原先 2 倍，组合缩放锚点同步移动。
- 缩放快慢方向尚未得到进一步确认，本轮按响应偏慢，将原生捏合及 Ctrl/Command + 像素滚动的缩放指数增量提高至原先 1.5 倍。鼠标离散滚轮不变。
- 直接使用本帧输入，不添加额外缓动或堆积手势；不改文档坐标和节点尺寸。

验证包括 1× / 1.5× / 1.75× / 2× DPI 下的屏幕平移距离、组合平移/缩放锚点、正反捏合复原、焦点与取消、鼠标滚轮行为。使用合成 Bevy / winit 事件，不能替代实体触控板手感或输入延迟测量。

本轮执行 `cargo fmt --all --check`、`cargo test --release --workspace --locked`、`cargo clippy --release --workspace --all-targets --locked -- -D warnings`、`cargo build --release --locked`。308 项测试通过、27 项忽略、0 项失败，格式与 Clippy 通过。共享工作区的其他会话改动不纳入此提交。

发布构建通过，使用 Linux 安装脚本更新本机，并核对安装二进制与构建产物一致。重启生效，实体触控板手感仍待用户确认。
