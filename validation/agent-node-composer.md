# Agent 卡片与选区对话验收

日期：2026-10-12。入口：Rust / Bevy 原生画布，深色主题。

## 实现范围

- 移除左下角统计胶囊；导出结果和跳转提示保留在顶部工具区，未保存状态仍在文档标签中。
- 使用已有绑定识别 Agent Section，呈现透明头像、任务名称、真实状态、短摘要与文件名。普通文字、知识节点不按名称伪装成 Agent。
- 折叠尺寸使用同一投影供显示、选择与连线使用；运行完成不自动展开大段记录。
- 只在单选 Agent 时显示节点下方输入框。普通节点、多选和取消选择时隐藏。草稿按文档实例与节点分开，长消息滚动显示。
- 输入框获得焦点后，点击空白画布的同一次按下可继续传给画布；保留模态窗口和输入法组合输入的捕获约束。
- 成功完成的任务 Agent 可接收后续消息：新增同任务 Run，以上一版 Run 为固定来源。原始运行、其他已完成任务和文档副本的控制权限不变。
- 运行中及特殊规划 / Skill 节点不支持追加执行消息；归档节点未连接本机流程时不能发送。运行命令被拒绝时保留草稿。

## 自动回归

`cargo fmt --all --check`、`cargo test --release --workspace --locked`、`cargo clippy --release --workspace --all-targets --locked -- -D warnings` 和发布编译使用独立已提交快照，排除其他会话未提交的修改。

完整测试结果：332 项通过、28 项忽略、0 项失败；格式检查与 Clippy 通过。忽略项不计入已验收范围。

新增回归覆盖：单选绑定识别、普通节点和多选不显示对话入口、文档间草稿隔离、归档不获取运行权限、发送失败保留草稿、输入焦点交还，以及后续消息只新增目标 Agent 的运行并保留固定成果来源。

Linux x86_64；X11 / Xvfb；Vulkan lavapipe；窗口 1280 × 800。使用本地 Fake 执行器生成的五 Agent `.mio` 归档测试文件，截图中的名称及成果为测试数据，不代表真实模型验收。

- [单选 Agent](agent-node-composer.png)：输入框显示在对应卡片下方，归档状态明确，发送禁用。
- [退出输入并取消选择](agent-node-composer-dismissed.png)：先选中 Agent，再点击输入框，最后只点击一次空白处；对话框隐藏，卡片取消选择。
- 左下角无统计胶囊，原生节点与连接保持可见；未修改用户项目。

本轮不包含真实供应商调用、macOS / 原生 Wayland 输入法实机验收、帧耗时基准或 PNG 导出中特殊卡片样式的一致性验收。后续消息的执行与历史保留通过本地测试执行器验证。
