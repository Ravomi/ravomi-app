# 嵌套回答关系网

2026-10-12，Linux / Bevy 0.19.1。替代新文字任务的树形输出约束。

- 归属与语义关系分离：父节点包含成员时生成 Section，支持继续嵌套和原生折叠。独立关系可以跨组、汇入共享概念及形成有意义的回路，边上保留关系名称。
- `summary` 保存 JSON 编码字符串，节点与边使用运行内 ID。投影后继续沿用 `answer_maps` 的 Run 来源，不改变 SQLite `.mio` schema。
- 已保存的结果不自动迁移。旧列表仍可读取；模型产生无效结构时进入既有错误提示，预检避免写入半张关系网。
- 布局为分组网格和组内嵌套，不是力导向布局；复杂跨组线仍可能交叉。

测试覆盖嵌套 Section、跨组连线、两个节点关联同一概念、语义回路、保存重开、非法归属循环、重复 ID 及悬空关系。截图采用固定 Git 示例，不冒充模型实际回答。
