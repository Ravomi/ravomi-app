# 原生画布代码协作与选区 Skill

日期：2026-10-12。环境：Linux x86_64，Bevy 0.19.1。原生 Wayland 显示使用 Intel Iris Xe / Mesa Vulkan；交互烟测使用 Xvfb/X11 + Mesa lavapipe，不作为性能测量。Xvfb 下硬件驱动缺少 DRI3 呈现支持，已切换软件 Vulkan 驱动验证窗口操作。本轮未验收 macOS/Windows。截图中的任务由可控测试执行器生成，不是本轮真实模型执行截图。

## 操作入口

1. 启动默认原生画布，打开右上角“Pi · 画布协作”。在“项目与模型”里填写代码项目、允许读取的相对文件路径、模型；API Key 仅保留在进程内，也可使用已有环境配置。测试命令填写 JSON argv 数组，留空数组不授权测试。
2. 在文本块或分组中写任务，结束文字编辑，选中后按 Space。该操作明确授权本次规划和计划内有界执行；普通选择、连线和拖动不执行。最多两个 Agent 并行，沿用现有调用预算、取消和固定版本交接。
3. 规划及计划内每个 Agent 各有一个折叠 Section。节点显示名字与状态，记录子节点显示运行编号、父代理和输出预览；完整记录、停止分支、重试、审阅、测试与导出在协作面板。节点日志固定预览尺寸，避免流式输出撑动画布。
4. 框选多个 Agent，点击“总结选区为 Skill…”，或使用“按列表选择 Agent”。清单可排除某次运行；生成时固定证据，携带失败/在途状态、依赖、重试和审阅信息，不混入后来的运行版本。
5. 生成成功后，在相应运行中“打开 Skill 草稿”，编辑并审阅，确认保存到目标代码项目 `.agents/skills/<name>/SKILL.md`。同时新增 `references/ravomi-provenance.json`。同名或符号链接目录拒绝保存；取消编辑不安装任何文件。

## 回归覆盖

- 递归分组输入去重，不把生成的 Agent 日志隐式纳入下一次任务。
- 计划节点唯一、默认折叠、输入块不被覆盖、删除节点不会自动重建。
- `.prg` 保存/重开保留 Agent 绑定；节点移动不改变运行身份。
- 固定 Run 来源、失败/运行中状态、缺失引用拒绝；Skill 生成走现有异步执行器。
- 完整草稿保存、来源记录、非法名字/frontmatter、同名不覆盖、项目目录符号链接拒绝。
- 运行目录文件锁拒绝第二个写入者，释放后允许恢复；重启不自动重发。

## 验证命令

本轮下列格式、workspace 测试、Clippy 和构建检查均通过。原生交互烟测已实际框选五个 Agent，打开 Skill 来源预览；见 [截图](canvas-ai-selection.png)。关闭恢复测试同时覆盖后台线程收尾，防止模型完成后仍有持锁线程造成重开竞争。

```sh
cargo fmt --all --check
cargo test --release --workspace --locked
cargo clippy --release --workspace --all-targets --locked -- -D warnings
cargo build --release --locked
bash -n packaging/linux/install-app.sh
```

测试用 `RAVOMI_CANVAS_AI_FIXTURE=/tmp/ravomi-canvas-ai.prg` 可导出明确标记的可控执行器画布及运行快照；默认测试不导出这些文件。原生截图验证真实 GPU 画布、折叠节点和连线；不据此声称真实模型总结质量已通过。

## 当前边界

- Agent 数量来自已经验证的计划；支持计划内父子检查任务，尚不支持模型在执行中自由调用工具动态派生任意子代理。
- Skill 为人工审阅的工作流说明，不是已经验收的可执行子图；未实现新任务自动加载、参数绑定和权限续用，也未实现同名 Skill 的差异合并。
- 原生画布和 Tauri 分别保存运行，未实现跨入口迁移。画布附件只保存绑定，完整源码/运行证据在本机数据目录；分享画布不等于分享完整运行库。
- 生成证据排除源码及原始日志，替换项目根目录并遮蔽常见密钥形式；审阅仍需确认草稿中项目私有值与许可证引用。来源记录保留原许可证适用声明，不重新授权原项目内容。
- 本轮新增 Skill 流程使用可控执行器回归；先前 DeepSeek 真实代码调用验收见 [原 MVP 记录](code-collaboration-mvp.md)，不能当成本轮真实 Skill 调用验收。
