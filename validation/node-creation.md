# 空白双击新建文字节点

> 历史证据：以下保留原创建手势、特效和 2026-10-09 的测试结论，不代表 Ravomi 的任务模块或 Agent 创建已经实现。模块语义以 [PRD](../PRD.md) 为准，交互与视觉以 [DESIGN](../DESIGN.md)、[AI_UI_RULES](../AI_UI_RULES.md) 为准。后续新增创建入口需复验焦点、取消、归组、撤销及清晰的创建反馈，不默认继承白绿闪光。

对照 Project Graph master `1fb1b5cc77d5d5a3820cbae4f5d5777339af63a0` 的 `ControllerEntityCreate`、`ControllerClass`、`StageNodeAdder` 和 `Settings`。复用已有 Bevy 鼠标事件、命中检测、UUID、文档历史、PRG 序列化与特效 mesh，不增加依赖或自行实现通用输入/序列化库。

左键在空白处完成两次点击后创建：两次释放间隔小于 300 毫秒、距离小于 20 逻辑像素。单次按住时移动超过 5 像素视为拖动，返回原点也不会触发创建。创建发生在第二次释放后，默认文本 `...`、字号 32、自动尺寸、透明底色，选中新节点而不自动进入编辑。

已有节点、连线、分组标题/边缘不作为空白；分组内部允许新建，归入最内层分组并遵守祖先锁定。平移、连线、Alt 跳跃、修饰键选择、界面捕获、失焦、离开窗口或视角变化会取消创建手势。

普通空白新建的白绿闪光是本轮新增反馈，复用 master `EntityCreateFlashEffect.fromCreateEntity` 的三层矩形效果；原版的这项特效主要在进入编辑时触发，不能称为空白双击原有行为的逐帧复刻。这里让 15/30/45 帧三层各自完成，避免原版父效果过早结束导致子层被丢弃。在分组内新建还复用 `RectanglePushInEffect` 的四角归组光线。

创建是一条独立撤销记录；保存包含完整 TextNode 数据、组成员关系，并保留原文件中存活对象的未知字段和 ZIP 附件。回归覆盖点击与拖动区别、取消与 UI 输入隔离、默认值、归组与锁定、创建/编辑/分组/连线/删除的撤销重做和保存往返。

首次字体测量按新旧尺寸差保持创建中心；共享首次测量结果同步到相关历史快照，避免先拖动再测量或撤销重做时跳回原点击位置。已加载节点和后续文本编辑仍保持原有左上角排版规则。
