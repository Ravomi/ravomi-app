# 深色首页参考图落地验收

日期：2026-10-12。范围：原生 Rust / Bevy / egui 首页。按用户确认的深色桌面参考重做，首页固定深色，画布原有主题独立保留。React/Tauri 原型不在此次修改范围。

## 实现

- 一体化石墨外壳、左侧导航、顶部首页标签与窗口操作、透明品牌猫、主标题及分隔线。
- 两列真实画布预览，节点/连接数、名称和文件修改时间；支持搜索、列表切换和卡片菜单。未将修改时间伪称为打开时间。
- 首页隐藏原画布胶囊标签与协作入口；返回、新建及打开画布沿用原文档行为。
- 复用深色语义主题；颗粒仅保留在猫素材内。透明资产的来源及完整编辑提示见 [资产记录](../assets/branding/ravomi-avatar-cutout.md)。

## 本次验证

环境：Linux x86_64，Xvfb / X11，Mesa lavapipe Vulkan，1280 × 800 实际应用窗口。通过 XTest 操作发布二进制并截取窗口，不是静态页面拼图。未测量帧耗时，未进行 macOS AppKit 实机验收。

| 检查 | 结果 |
| --- | --- |
| 默认主题与 `--dark` 启动首页 | 均呈现深色首页 |
| 100% 双列布局 | 四张卡片完整显示，无横向溢出 |
| 200% 缩放 | 单列、滚动区域，搜索及导航可见 |
| 列表切换 | 显示四行真实预览及元数据 |
| 顶部搜索入口 | 聚焦搜索；输入 `ravomi-canvas-ai` 后仅剩匹配卡片 |
| 卡片省略号 | 打开文件位置 / 删除菜单可见 |
| 首页标签关闭 | 返回已载入的 603 节点画布，保留原浅色主题 |
| 新建画布 | 进入新的空画布标签 |
| 点击最近项目 | 打开对应画布 |

交互检查发现并修正 Grid 中菜单按钮占用额外列、侧栏底部滚动溢出，以及点击主工作区后标题栏被背景遮住的问题。标题栏使用显式前景层，并复查列表 / 网格切换后的显示。

```sh
cargo fmt --all --check
cargo test --release --workspace --locked
cargo clippy --release --workspace --all-targets --locked -- -D warnings
cargo build --release --locked
```

结果：307 项通过，27 项忽略，0 项失败；格式、Clippy 和发布构建通过。忽略项未在本轮运行；不将 Xvfb 冒烟截图等同于全部 GPU / 系统字体测试通过。测试运行在共享工作区，其他会话未提交的改动未纳入本功能提交。
